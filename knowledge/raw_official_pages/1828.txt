Boosting World Server
The Boosting World server is a growth-specialized server designed to provide new and returning Dragonians with the thrill of rapid growth during a designated period, helping them quickly join the battlefields of MIR4.
What is the Boosting World Server?
Boosting World Server Rules
Boosting World Server Information
Boosting World Server Benefits
What is the Boosting World Server?
– The Boosting World server offers various benefits to help new characters grow quickly.
– The Boosting World server operates only for a set period and will be converted to a regular server once the period ends.
Boosting World Server Rules
1. Only one character can be created per account on the Boosting World server.
2. Tradeable items cannot be obtained through Crafting or Combining on the Boosting World server.
3. Some content will be restricted to allow players to focus solely on growth without interference from other servers.
