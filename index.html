💰 Fair value
  • Fair (power) = the middle price of similar characters sold in the last ~90 days, adjusted to this character's power.
  • Similar = same class within 5% power. If fewer than 3 sales, it widens to any class within 5%, then 10%.
  • Fair (full build) = a price model trained on recent sales that looks at the whole build, not just power.
  • "Why" shows the 3 build parts that move the price most vs an average sold character.
Price grows about with power^6.7, so comps are scaled on that curve, not linearly. The headline fair uses the full-build model when it is confident; if comps are thin, from another class, or 5%+ away in power, it blends the model and the comps (geometric mean). The model is a ridge regression on log price using power, level, class, dragon-refined gear, gear enhance, Mythical/Legendary spirits, potential, Darksteel and Ancient Coins.
🔥 Deals and flips
  • Deal = 15%+ under fair value, with at least 3 similar sales.
  • Discount uses the full-build value when it beats power-only in testing and confidence is OK. ⚠ = few similar sales.
  • Flip flag = sold within the last 8 months and now listed 40%+ higher.
  • Flip margin = what you'd net reselling at fair (after the 5% fee) vs the price. Hidden unless "Show flip info" is on.
Flip margin = (fair × 0.95 − price) / price.
✂️ Relisted and price cuts
  • Relists = delist events in the Hofgamer trade history.
  • Relisted / price cut badges come from our own daily tracker: the same character (name + server + class) seen again with a new listing or a different price.
  • Changes are compared with the first price we saw. History is kept since Oct 20, 2026.
Stored in data/relist_history.json.
🕒 Times and servers
  • Listed times come from Hofgamer in UTC+8 and are shown in Pacific time.
  • A sealed character only loads on its own server, so set the Region filter to where you play.
📊 Stats
  • ATK = the higher of PHYS or SPELL ATK. DEF = PHYS + SPELL DEF.
  • Also shown: Skill ATK boost, PvP ATK boost and EVA, from each character's Hofgamer stat sheet.
  • "Top X%" ranks the character within its class among current listings and recent sales.
⚙️ Build score
  • A 0 to 100 score: how this character ranks in its class on the key stats, vs current listings and recent sales.
  • ATK counts the most. Skill ATK, PvP ATK, DEF and PvP damage reduction also count. Taoist and Warrior also count EVA.
  • Strong build = top 25% build score in its class among current listings.
Most classes: 36% ATK, 18% Skill ATK, 18% PvP ATK, 18% DEF, 10% PvP DMG reduction. Taoist and Warrior: 27% ATK, 18% Skill ATK, 18% PvP ATK, 18% DEF, 9% EVA, 10% PvP DMG reduction.
🏆 Best buy sort
  • The default sort. It rewards a strong build that is also priced under fair value.
  • Overpriced characters get pushed down.
  • Only listings within your Max $ budget are ranked.
Best buy = build score + 1.5 × discount % (discount is % under the full-build fair value, negative if over).
