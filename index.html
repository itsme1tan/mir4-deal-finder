How fair value, build score and badges work
Fair (power) = median of comparable sales in the last ~90 days (same class within ±5% power; widens to any class ±5%, then ±10%, if under 3 comps), each scaled to this character's power on the fitted price curve (price grows about with power^6.7, so linear scaling badly misprices comps that sit 5-10% below or above). Headline fair: full-build model when confident; otherwise, if comps are thin, another class, or 5%+ away in power, a blend (geometric mean) of the model and the power-adjusted comps. Fair (full build) = ridge regression on log price of recent sales using power, level, class, dragon-refined gear, gear enhance, Mythical/Legendary spirits, potential, Darksteel and Ancient Coins; 'Why' shows the 3 biggest build effects vs an average sold character. Discount and the deal badge use the full-build value when the model beats power-only in cross-validation and confidence is OK (⚠ = few similar sales). Deal = 15%+ under fair value with 3+ comps. Flip margin = (fair × 0.95 fee − price) / price. Flip flag = last sale within 8 months and now listed 40%+ higher. Relists = delist events in Hofgamer trade history. Relisted/price cut badge = our own daily tracker: the same character (name + server + class) seen again under a new listing id or a different ask, compared with the first ask we saw (history in data/relist_history.json, since Oct 20, 2026). Listed times come from Hofgamer in UTC+8 and are shown in Pacific time. Server region filter: a sealed character only loads on its own server, so pick the region you play in. Stats (ATK = higher of PHYS/SPELL ATK, Skill ATK boost, PvP ATK boost, DEF = PHYS+SPELL DEF, EVA) come from each character's Hofgamer stat sheet; 'Top X%' ranks within the same class among current listings and recent sales. How build is calculated: build score = weighted in-class percentile ranks vs current listings and recent sales. Most classes: 36% ATK, 18% Skill ATK, 18% PvP ATK, 18% DEF, 10% PvP DMG reduction. Taoist and Warrior: 27% ATK, 18% Skill ATK, 18% PvP ATK, 18% DEF, 9% EVA, 10% PvP DMG reduction. ATK = higher of PHYS/SPELL ATK, DEF = PHYS+SPELL. Strong build = top 25% build score in class among current listings. Best buy (default sort) = Build score + 1.5 × discount %, where discount is % under fair (full build) value (negative if over); only listings within your max budget are ranked. Flip info is hidden unless 'Show flip info' is on. Data: nft.hofgamer.com (public), price: CoinGecko. Read-only; buy only on XDRACO yourself. Not financial advice.
